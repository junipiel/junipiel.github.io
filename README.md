# junipiel.com

Personal website for Julian Pielmaier, built with [Astro](https://astro.build/) and deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
```

## Deployment

Pushes to `main` are deployed through `.github/workflows/deploy.yml`. In the repository settings, set the GitHub Pages source to **GitHub Actions** and configure `junipiel.com` as the custom domain.
